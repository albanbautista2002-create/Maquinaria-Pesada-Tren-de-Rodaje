# Mini curso: Tren de rodaje de maquinaria pesada

Sitio educativo interactivo preparado para publicarse con **GitHub Pages**.

## Contenido
- Introducción al tren de rodaje.
- Componentes principales y explicaciones desplegables.
- Funcionamiento paso a paso.
- Lista interactiva de inspección.
- Desgaste y mantenimiento preventivo.
- Seguridad.
- Evaluación automática de 8 preguntas.

## Publicar en GitHub Pages

1. Inicia sesión en https://github.com/.
2. Crea un repositorio nuevo, por ejemplo `curso-tren-de-rodaje`.
3. Elige la opción **Public** (Público).
4. Sube el archivo `index.html` de esta carpeta al nivel principal del repositorio.
5. Abre **Settings → Pages**.
6. En **Build and deployment**, selecciona **Deploy from a branch**.
7. Selecciona la rama `main` y la carpeta `/ (root)`. Pulsa **Save**.
8. Espera a que GitHub Pages publique el sitio. La dirección aparecerá en la sección **Settings → Pages** y tendrá un formato similar a:
   `https://TU-USUARIO.github.io/curso-tren-de-rodaje/`

## Nota
El curso es autocontenido: sus estilos, ilustraciones SVG y funciones JavaScript están incluidos en `index.html`. No necesita instalar dependencias ni configurar un servidor.
